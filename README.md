# Your Patakha V6 — corrected results and lettering

Extract the ZIP and open `index.html` in Chrome or Edge. Keep `assets/`,
`style.css`, and `game.js` in the same extracted directory.

## Changes from V5
- Sutli Bomb instantly ends the round and plays the original blast,
  but never becomes the player's patakha.
- **Every** result (timer expiry and Sutli Bomb) is based on score:
  - 0–219: PHULJHADI
  - 220–499: ANAAR
  - 500–899: CHAKRI
  - 900+: ROCKET
- Result headline "YOU’RE A" is live, readable HTML, shifted lower
  on the original poster ribbon, with more separation from the name.
- Original artwork, music toggle, soundtrack, sound effects, home/replay,
  timer, and gameplay stay in place.

No network required to play; Cabinet Grotesk loads via Fontshare only
when a connection is available. The soundtrack is copyrighted and may
require permission for public distribution.
